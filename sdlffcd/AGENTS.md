sdlffcd is a standalone D application that uses sdlffcd_clib C library to bridge calls to thirdparty C libraries.
See @sdlffcd_clib/AGENTS.md

All C library dependencies are accessible via sdlffcd_clib, see @sdlffcd_clib/README.md

source/sdlffcd_clib.d must contain D declarations that match sdlffcd_clib.h

Put conversation artifacts like plan.md and walkthrough.md to doc-archive directory giving the files appropriate names (in case of conflict, choose a different name).

Use samplevideo.mp4 for testing playback.
