In @sdlffcd_clib using avutil/avformat etc. implement public video file open, close, stream/media info, decoding a frame functions. The get_media_info function (what format, what codecs, what streams, what duration, fps) and decoding frame functions to be accessible in D code. The functions share a video file context structure passed as the first argument. The video context structure to hold necessary data to work with avutil, avformat etc to support future video decoding and playback using libsdl, and to free the resources on file close.
