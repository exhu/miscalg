Change current keys and add new features based on the following description:

Space         Pause / Resume video playback

V             Cycle current time overlay position (Top-Left -> Top-Right -> Bottom-Right -> Botton-Left -> Hidden)
Enter         Print lossless FFmpeg cut command to stdout
Q / Esc       Quit application (auto-prints FFmpeg command if markers modified)
